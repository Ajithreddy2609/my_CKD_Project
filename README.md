# 🩺 Chronic Kidney Disease (CKD) Analysis System
This project is a Full-Stack Machine Learning Web Application that predicts the likelihood of Chronic Kidney Disease (CKD) based on 24 clinical parameters. It features a responsive UI, a FastAPI backend, and a Random Forest classification model.

# 🚀 Live Demo
Frontend: https://ajithreddy2609.github.io/my_CKD_Project/

Backend API: https://my-ckd-project.onrender.com/

# 📖 Project Overview
This project was developed as a B.Tech Final Year Project to address the critical need for early-stage screening of Chronic Kidney Disease (CKD). Using a robust machine learning pipeline, the system analyzes 24 unique clinical parameters to provide a diagnostic insight with high statistical accuracy.

# ✨ Key Features
Real-time Prediction: Uses an AI pipeline to analyze clinical data and provide instant results.

Diagnostic Insights: Automatically categorizes laboratory values (e.g., Hemoglobin, Creatinine) as "Normal" or "Abnormal".

Medical Guidance: Includes built-in professional recommendations to consult a physician.

Responsive Design: Fully optimized for mobile and desktop viewing using Tailwind CSS.

# 🛠️ Technical Stack
Backend: FastAPI (Python 3.12), FastAPI, Uvicorn.

Frontend: HTML5, Tailwind CSS, JavaScript (Fetch API).

Machine Learning: Scikit-Learn(Random Forest), Pandas, NumPy.

Deployment: GitHub Pages (Frontend) & Render (Backend API).

# 🧠 Why Random Forest?
In my comparative analysis, Random Forest was selected over Logistic Regression for two technical reasons:

Handling Non-Linear Relationships: Clinical markers rarely have a simple linear correlation; the decision trees in Random Forest capture complex, non-linear interactions between attributes.

Robustness to Missing Data: Clinical datasets are notoriously "dirty." The bagging mechanism in Random Forest maintains predictive power even when certain patient markers are missing or noisy.

# 📊 Clinical Methodology
The model evaluates a comprehensive set of features, categorized into:

Laboratory Values (Numerical): Serum Creatinine, Hemoglobin, Specific Gravity, and Blood Pressure.

Clinical Findings (Categorical): Presence of Hypertension, Diabetes Mellitus, Anemia, and Pedal Edema.

Key Indicator Insight: The model places high "Feature Importance" on Specific Gravity and Albumin, as these are the earliest indicators of kidney filtration efficiency failure.

# 📊 Evaluation & Medical Ranges
The system evaluates features against standardized reference ranges:

Serum Creatinine: Normal: 0.6 - 1.2 mg/dL.

Hemoglobin: Normal: 13.5 - 17.5 g/dL.

Blood Pressure: Normal: 60 - 120 mm/Hg.

Specific Gravity: Normal: 1.005 - 1.030.
